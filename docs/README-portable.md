# The Bible Maker — Portable Windows x64 Package

## English

For Windows 10/11 x64. Extract the complete ZIP into a writable folder and run the executable (`iBiblia.exe` in the v2.0.0.001 transition package). Keep the supplied executable, DLLs, `cacert.pem`, model catalog, languages, notices, and licenses together. No installer is required.

Before updating, save and close The Bible Maker, back up the closed `.tbm` (or `.bib`) project, and keep the previous application folder. Preferences save to `TheBibleMaker.ini` (migrating automatically from an older `iBiblia.ini` on first launch); preserve any customized `iBiblia.models.json`.

Projects use `.tbm` (with full support for legacy `.bib` files). Global AI and GitHub tokens use Windows Credential Manager locally and do not travel with project copies. AI assistance is optional, requires internet and a provider key, and sends relevant texts/instructions/examples to the selected provider.

- Built-in User Guide: press `Shift+F1` inside The Bible Maker
- Releases & Issue Tracker: https://github.com/SalitaNgDiyos/The-Bible-Maker/releases and https://github.com/SalitaNgDiyos/The-Bible-Maker/issues

## Português

Para Windows 10/11 x64. Extraia o ZIP inteiro para uma pasta em que possa gravar e execute o programa (`iBiblia.exe` no pacote de transição v2.0.0.001). Mantenha executável, DLLs, `cacert.pem`, catálogo de modelos, idiomas, avisos e licenças juntos. Não é necessário instalador.

Antes de atualizar, salve e feche o The Bible Maker, faça backup do projeto `.tbm` (ou `.bib`) fechado e mantenha a pasta da versão anterior. As preferências ficam em `TheBibleMaker.ini` (com migração automática do antigo `iBiblia.ini` na primeira execução); preserve eventuais ajustes em `iBiblia.models.json`.

Projetos usam `.tbm` (com compatibilidade total para arquivos `.bib` legados). Chaves de IA e tokens do GitHub ficam no Gerenciador de Credenciais local e não acompanham cópias do projeto.

- Guia Interno: pressione `Shift+F1` no The Bible Maker
- Versões e Suporte: https://github.com/SalitaNgDiyos/The-Bible-Maker/releases e https://github.com/SalitaNgDiyos/The-Bible-Maker/issues
